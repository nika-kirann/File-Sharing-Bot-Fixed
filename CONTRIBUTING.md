# Contributing

This tree is a modified version of [CodeXBotz/File-Sharing-Bot](https://github.com/CodeXBotz/File-Sharing-Bot) (also published at [Kiranxer/File-Sharing-Bot](https://github.com/Kiranxer/File-Sharing-Bot)), released under the GNU GPL v3. Contributions are under the same license. See `LICENSE`.

1. Branch from `main`.
2. Keep secrets out of the source. Configuration belongs in environment variables.
3. Run `python -m compileall -q .` and `python -m unittest discover -s tests` before opening a pull request.
